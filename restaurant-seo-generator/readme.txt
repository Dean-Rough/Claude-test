== Description ==

Restaurant SEO Generator is a powerful WordPress plugin designed for solo operators and agencies building websites for small local businesses. It leverages Claude AI to generate high-quality, SEO-optimized content in minutes instead of hours.

**Perfect for:**
* Restaurants, bars, and cafes
* Home service businesses (plumbers, electricians, HVAC, etc.)
* Health & wellness providers (dentists, chiropractors, yoga studios, etc.)
* Professional services (accountants, lawyers, real estate agents, etc.)
* Beauty & personal care businesses (salons, spas, barbershops, etc.)

**Key Features:**

= Keyword Research =
* Generate keyword variations using Google Autocomplete (free, no API needed)
* Automatic intent classification (informational, commercial, transactional, navigational)
* Local keyword expansion based on your location
* Question keyword generation

= Competitor Analysis (Optional) =
* Analyze 2-5 competitor websites
* Extract word counts, heading structure, and common topics
* Identify content gaps and opportunities
* Use insights to create better content

= Site Architecture Generator =
* Business-type aware page structure recommendations
* Optimized for different industries (restaurants, home services, health, etc.)
* Smart keyword-to-page mapping
* Internal linking suggestions

= Content Generation =
* AI-powered content using Claude Sonnet 4
* Business voice matching from writing samples
* Natural keyword integration (no keyword stuffing)
* Local SEO optimization (location mentions, service areas)
* Comprehensive content covering all key topics

= HTML Output =
* Clean, copy/paste ready HTML
* Meta tags included (title, description, slug)
* Business-type specific schema markup (LocalBusiness, Restaurant, etc.)
* Works with any page builder (Elementor, Divi, WPBakery, etc.)

= Simple Workflow =
1. Create site profile (business info, location, voice)
2. Generate keywords (automated expansion)
3. Analyze competitors (optional but recommended)
4. Review site architecture (AI-generated page plan)
5. Generate content (20-25 minutes for 10 pages)
6. Copy/paste HTML into your site builder

**Cost Per Site:**
* Keyword research: ~$0.10
* Architecture generation: ~$0.05
* Content generation: ~$0.20 per page
* **Total: $2-3 per 10-page site**

Way cheaper than hiring writers or using other AI tools!

**Requirements:**
* Claude API key (get one at console.anthropic.com)
* WordPress 5.8 or higher
* PHP 7.4 or higher

== Installation ==

1. Upload the `restaurant-seo-generator` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to SEO Generator → Settings and enter your Claude API key
4. Start creating sites and generating content!

= Getting a Claude API Key =

1. Go to https://console.anthropic.com
2. Sign up for an Anthropic account (if you don't have one)
3. Navigate to API Keys section
4. Create a new API key
5. Copy the key and paste it into the plugin settings
